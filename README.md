# Kaushal Setu AI (कौशल सेतु AI)
### AI-Driven Voice Assistant for Livelihood Mapping and NSQF-Aligned Skilling Recommendations for SC Communities under GIA Component of PM-AJAY

**Smart India Hackathon 2026**
- **Problem Statement ID**: SIH26097
- **Theme**: Agriculture, Food Tech & Rural Development
- **Team**: SixSnipers (Team ID: 175248)
- **Component**: PM-AJAY (Grants-in-Aid Component)

---

## 🌟 Key Features

1. **🎙️ Multilingual AI Conversational Voice Profiler**:
   - Voice-first interaction powered by Web Speech API (Speech-to-Text & Speech Synthesis in Hindi & English).
   - Conversational profiling for low-literacy rural SC youth & traditional artisans.
   - Quick 1-click answer chips for rapid demonstration.

2. **🪪 Digital Livelihood Profile & Official Beneficiary ID**:
   - Auto-extracts informal/traditional skills and maps them to National Occupational Standards (NOS).
   - Generates official PM-AJAY Laminated Beneficiary ID with QR code verification and 1-click PDF/Print.
   - Computes NSQF Level 4 Readiness Score & identifies safety/digital billing gaps.

3. **🎯 NSQF-Aligned Recommendation Engine**:
   - Verified Qualification Packs (Solar PV Installer, Organic Grower, Handloom Weaver, Assistant Electrician).
   - **Explainable AI (XAI)** popup: Transparent reasoning across Skill Match, Eligibility, District Demand, and Accessibility.
   - 100% GIA Grant Coverage (100% Free Training + Monthly Stipend).

4. **📍 Interactive GIS Opportunity Map & Training Locator**:
   - Visual radius-based map showing nearby PMKK, KVK, and CFC cluster centers.
   - Travel duration, distances, and free hostel accommodation details.
   - PM-AJAY GIA Special Tool-Kit Grant (₹50,000) & Micro-Enterprise Seed Capital (Up to ₹2,00,000).

5. **📱 WhatsApp & IVR Voice Simulator**:
   - Interactive WhatsApp voice note simulation for non-smartphone or low-connectivity feature phone users.

6. **📊 PM-AJAY Officer / Government Web Dashboard**:
   - District-level analytics (Total SC Profiled, In Training, Certified, Placed/Enterprise, GIA Funds Disbursed).
   - Live Beneficiary Registry with real-time progress bars, search, status filters, and 1-click CSV export.

## 🛠️ Getting Started Locally

```bash

# Navigate to project folder
cd Kaushal-setu

# Install dependencies
npm install

# Start development server
npm run dev
```
